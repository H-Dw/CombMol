# 选区、连接与恢复能力：分析前逻辑

仅分析已保存的675次终态和27套条件；不重新采样、不改写冻结协议，不把新增诊断作为旧结果的新合格门槛。

    EvidenceLoad:
        校验原证据包哈希，按target、fusion、node_id和原始source_atom对应读取。
        保留共同蛋白坐标系及原有原子槽；区分完整父本、被选片段和实际终态。
    RegionGeometryMeasure:
        测量跨片段最近距离、范德华半径归一化距离、质心间距。
        从源父本实际断键得到所有连接出口、方向及连接端点间距。
        记录固定原子数、连通片段数、自由原子数与方向诊断；方向不是新的硬阈值。
    InteractionCoverageMeasure:
        对比完整父本、选中区域及实际终态的PLIP互作。
        分开记录残基/类型指纹、具体接触原子集合及原评价中“每侧至少一个”的标准。
        测量两侧重复互作和所选区域的化学拓扑多样性，不把互作计数当能量。
    TerminalDeformationMeasure:
        在固定对应槽上比较蛋白坐标系RMSD、两侧共同proper-Kabsch拟合RMSD。
        同时测量各片段内部拟合误差、跨片段距离矩阵误差和质心间距改变。
        不反射、不缩放、不重匹配；共同拟合仅诊断相对构型，不能替代原蛋白坐标系评价。
    AttachmentAudit:
        统计实际固定—自由键是否接在原始出口，及不允许的跨父本固定原子直接成键。
        在条件化学保持子集中讨论构型与连接位置，避免把原子类型改变等同原结构运动。
    AffinityStratify:
        使用同一方案真实父本成绩计算逐候选pIC50差值。
        分层比较全部可构建、条件化学保持、相对构型保持、原协议合格和PB通过子集。
        在各教师内按方案作描述性相关；不将同方案25个样本当25个独立方案。
    EvidencePacketAssemble:
        输出来源绑定的StatePacket、逐方案/逐候选测量表、覆盖限制与中文解释。
        将实测事实、机制假设和后续验证方案分开；不声称从相关性证明因果。
