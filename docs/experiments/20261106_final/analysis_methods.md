# 完成结果的核验与汇总逻辑

本文件先于本次独立分析脚本编写。分析不调用模型、不生成候选、不更改冻结条件。

    ReceiptCheck:
        确认最后一次任务结束、旧进程已退出、源提交和配置哈希一致。
        检查原始归档、checkpoint、冻结上游源码及已完成选择的哈希。
    SlotAudit:
        对每个靶点及方案按五种子乘五候选核对唯一槽。
        校验初始化张量哈希、终态文件哈希、五条原始记录及对应评价。
        所有未构建结构仍保留在675次尝试分母内。
    GeometryAudit:
        从终态分子和固定区域重新计算蛋白共同坐标系中的条件RMSD。
        独立核对固定原子/内部键、连通性、clash与双方接触恢复。
        不单独拟合两个配体，不修改终态。
    AggregateTables:
        按候选原始记录重算各方案的构建数、合格融合数及pIC50均值/最佳。
        按候选加权汇总靶点，明确区分全部可构建结构与合格融合子集。
        对比方案双方父本和该靶点八个父本中的最高分。
    ReportWrite:
        保留父本、逐候选和逐方案CSV、独立审计及原始小体积证据包。
        报告构建失败、诊断缺失、筛选分母和科学解释限制。

“合格融合”沿用冻结协议：连通、固定条件化学保留、两侧条件区域在共同蛋白坐标系中的RMSD均严格低于0.5Å、无严重蛋白clash、双方至少一个预期PLIP互作恢复。PoseBusters为诊断，不将其全部通过作为新门槛。

pIC50仅为冻结FLOWR模型对实际离散终态的端点预测，不代表测得的活性。均值不以方案均值再次平均；合格融合均值按全部合格候选加权。失败构建没有pIC50，明确保留其数量和675次总体分母，不以删样伪造生成成功。

初始化检查比较完整张量输入，而非仅比较坐标。当仅有一个自由原子时，原生零质心高斯先验会把该原子的相对坐标置于零；坐标相同本身不代表重复初始化。三批此类输入的分类特征仍然不同，全部135批均保留五个不同的完整初始输入。
